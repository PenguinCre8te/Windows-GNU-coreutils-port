# Windows GNU coreutils port

Windows GNU coreutils port is a (almost) **POSIX compliant, no emulation** GNU coreutil port for windows

## Installation

Use a windows aware compiler (I use clang) to compile with the makefile

```bash
make build
```

## Usage

Use 
```bash 
tool --help
``` 
to view the useage
